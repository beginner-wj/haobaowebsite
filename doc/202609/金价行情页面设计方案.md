# Haobao 网站「金价行情」页面设计方案

> 文档日期：2026-09-24
> 范围：将现有金价展示功能（孙健原功能）升级为图 1（Pioneer Horizon 参考页）形式的独立「金价行情」页面，并实现 Market Reference Prices 数字的全自动采集。

---

## 1. 背景与目标

- 现状：网站（www.haobao.com.sg，Cloudflare Pages + Functions）的产品区已有一处金价/银价小部件（每盎司指示价），数据来自 `functions/prices.js`（goldapi.io）。这些数字目前由人工从网上各站抽取。
- 目标：
  1. **自动取数**：Market Reference Prices 的所有数字改为由后端自动从网上拉取，不再人工抽取。
  2. **新增 CNY/g 与 CNY/troy oz 两行**，进入 Market Reference Prices 表格。
  3. **列顺序**严格按用户最新发的表格（doc/202609/2.png）：Global XAU/USD Spot → SGE Au99.99 → Shanghai Gold Benchmark（AM/PM）→ LBMA Gold Price（AM/PM）。
  4. **换算标准**：1 troy ounce = 31.1034768 g（用户指定精确值）；汇率（USD/CNY 等）也从网上自动拉取。
  5. **自有报价**（四个数字：BUY/SELL 的 USD/g 与 USD/troy oz）按当时 XAU/USD × 0.98（BUY）/ × 1.02（SELL）计算。
  6. 新增一个**功能页面**，即原孙健做的金价功能的升级版，改成图 1（doc/202609/1.png，Pioneer Horizon「Gold Pricing」页）的形式。

## 5. 换算逻辑（统一口径）

```
常量：1 troy oz = 31.1034768 g

USD/g    = USD/oz ÷ 31.1034768
CNY/g    = USD/g × USDCNY            （即 USD/oz × USDCNY ÷ 31.1034768）
CNY/oz   = USD/oz × USDCNY           （等价 CNY/g × 31.1034768）
SGD/g    = CNY/g ÷ USDCNY × USDSGD   （用于 SGE Au99.99 列）
SGD/oz   = SGD/g × 31.1034768

自有报价（四个数字）：
  SELL（向客户卖）= XAU/USD 实时 × 1.02 → USD/oz，再 ÷31.1034768 → USD/g
  BUY （向客户收）= XAU/USD 实时 × 0.98 → USD/oz，再 ÷31.1034768 → USD/g
```

- 显示精度建议：USD/oz、CNY/oz 保留 2 位小数；USD/g、CNY/g、SGD/g 保留 2~3 位（图 1 示例为 2 位；如需更细可 3 位，实施时确认）。
- 汇率与更新时间一并展示（页脚注：** USDCNY = XXX，last updated …）。

## 6. 后端设计（Cloudflare Pages Function）

### 6.1 接口

扩展现有 `functions/prices.js`（保持 `/prices` 路径不变，向后兼容现有 `xauusd`/`xagusd` 字段），返回完整 payload：

```json
{
  "updatedAt": "2026-09-24T09:30:00Z",
  "fx": { "usd_cny": 6.7227, "usd_sgd": 1.2793, "source": "open.er-api.com", "updatedAt": "..." },
  "markets": {
    "xauusd":      { "usd_oz": 4259.80, "usd_g": 136.96, "cny_g": 920.9, "cny_oz": 28635.6, "lastUpdated": "...", "status": "live" },
    "sge_au9999":  { "cny_g": 926.50, "sgd_g": ..., "sgd_oz": ..., "usd_g": ..., "cny_oz": ..., "lastUpdated": "...", "status": "delayed" },
    "sh_am":       { "cny_g": 936.31, "usd_g": ..., "cny_oz": ..., "usd_oz": ..., "lastUpdated": "...", "status": "benchmark" },
    "sh_pm":       { "cny_g": 935.50, "...": "..." },
    "lbma_am":     { "usd_oz": 4316.40, "usd_g": ..., "cny_g": ..., "cny_oz": ..., "lastUpdated": "...", "status": "benchmark" },
    "lbma_pm":     { "usd_oz": 4284.45, "...": "..." }
  },
  "quotes": {
    "buy":  { "usd_g": ..., "usd_oz": ..., "lastUpdated": "..." },
    "sell": { "usd_g": ..., "usd_oz": ..., "lastUpdated": "..." }
  },
  "sources": { "xauusd": "...", "sge_au9999": "...", "sh_benchmark": "...", "lbma": "...", "fx": "..." }
}
```

### 6.2 抓取流程

1. 并发请求所有源（Promise.all），各自带超时（如 8s）与 try/catch；单个失败不影响其他。
2. 换算统一在后端完成，前端只渲染。
3. 失败源降级：优先用 Cloudflare 边缘缓存旧值（`stale-if-error`），仍失败则该单元格显示「— / 无更新」。

### 6.3 缓存策略

| 数据 | 边缘缓存（s-maxage） | 说明 |
|---|---|---|
| XAU/USD、Au99.99 | 30–60s | 实时/延迟行情 |
| 上海金基准、LBMA | 10–15 min | 每日固定两次发布，短缓存足够 |
| 汇率 | 1h | 每日更新 |

沿用现有 `caches.default` + `stale-if-error=86400` 的写法，保证上游失败时页面仍有旧数据。

### 6.4 环境变量

- 保留 `GOLDAPI_KEY`（现有）。若改用 gold-api.com 免费源则无需 key，可作首选，goldapi.io 作备选。

## 13. 实施补充（2026-09-25）

- **命名更正**：列名与文案由「SGD Au99.99」改为「SGE Au99.99」（数据来自上海黄金交易所，SGD 只是换算显示）。
